## §0 What is established, and what it rests on

Everything below is measured on real data at **z = 1** and validated either against 585
hand labels or against the experimental design.

| Result | Number | Basis |
|---|---|---|
| **Granule finder** | **88.9% exact count**, held out | intensity h-maxima, σ = 4.0 px, h = 0.15 of the interior span, flooded on intensity inside the Otsu mask. Beat EDT h-maxima (81.7%) and every threshold variant. Otsu components are capped at 73.4%. |
| **Granule scale** | S 2078, M 3599, L 4030 µm² | median area of a *label-confirmed single* granule. **Replaces every nominal/sieve size in the workflow.** |
| **Merge rate (truth)** | 26.6% of objects, 40% of area | 585 labels; worst for SMALL granules (34.5 / 26.3 / 19.3%) |
| **Phantom-inert fix** | size filter, ≥ 0.30 × single-granule area | gate: pure-F wells 0.301 → 0.002; mixed wells keep 88–91% |
| **Void fraction** | **≈ 0.60**, consistent across four good conditions | 0.59–0.69 spanning pure-F to half-inert |
| **Void dynamics** | three conditions open, M11 **compacts −0.067** | bleaching check: trend 0.049 vs threshold artefact 0.015 |
| **Phase-specific packing** | inert carries **~45% more void per unit solid** | 2.79 vs 1.93 (M19), 2.52 vs 1.73 (M11) |
| **Cell preference** | **6–15× for F over I** | enrich F 1.00/2.70/5.74, enrich I 0.17/0.43/0.39 |
| **Cell speed** | 0.39 µm/min, straightness 0.73 | 47.3 min cycle, 11.0 h series |
| **Time base** | **47.3 min/frame, 11.0 h** | derived; the file declares `periodMs = 0.0` and carries no interval |

**Hard limits that constrain everything downstream:**

- **R-B is saturated** at the 12-bit ceiling over 0.2–9.1% of the field, in every frame. F
  **geometry** is usable; F **intensity** is not. This kills the intensity term
  `λ_I·½(I−µ)ᵀΣ⁻¹(I−µ)` for the functional channel and makes F bleaching unobservable.
- **Depth attenuation** limits the usable axial range to about **z = 0–3** of 7.
- **The finder is validated at z = 1 only**, and only at the three pure-functional conditions.
- **Granule linking across frames does not work yet** — mutual-NN matching 74–93%. This is
  the single blocking defect; see §2.
- **Two of six fields are bad** (M21 by level, M04 by continuity from t = 6). Expect ~1 in 3.

## §1 Phase 0 — make it runnable on a cluster *(prerequisite for everything else)*

The analysis currently lives in session scratch. Nothing can be scheduled until it is in the
repo behind a CLI.

**Deliverable: `scripts/_bed_analyze.py`** — one script, three modes, no GUI.

```
# per-plane analysis, one SLURM array task per chunk
python scripts/_bed_analyze.py analyze --out results/ \
       --positions 0-20 --timepoints 0-14 --z 0-3 \
       --task-id $SLURM_ARRAY_TASK_ID --n-tasks 64 --skip-existing

# link instances through time, per (position, z)
python scripts/_bed_analyze.py link --out results/

# aggregate to tables + figures on one node
python scripts/_bed_analyze.py reduce --out results/ --figures
```

Requirements, each of which has already bitten this project:

1. **One JSON per plane**, `results/planes/P{p:02d}_T{t:02d}_Z{z}.json`. Makes the job
   array-parallel with no coordination, resumable via `--skip-existing`, and lets a single
   corrupt plane fail without losing the run.
2. **`PYTHONUTF8=1` mandatory** and `matplotlib.use("Agg")` before any pyplot import. The
   `[ok]` reporting lines carry µ/σ and a cp1252 console raises inside the report itself.
3. **`--dry-run`** prints the task partition and exits without touching the data, so a
   1000-task array can be checked in a second.
4. **Path from `ND2_PATH` env var**, defaulting to the repo root. `*.nd2` is gitignored, so
   the cluster copy lives outside the tree.
5. **Deterministic**: explicit seeds, no `Date.now()`-style nondeterminism, sorted iteration.
   Two runs must produce byte-identical JSON.
6. **No Qt import anywhere in the path** — `scripts/_nodelab_v2_phase5_probe.py` is the only
   thing that may touch it.

**The I/O problem is the real bottleneck, not compute.** Per-plane segmentation is ~5–15 s,
so 21 × 15 × 4 z = **1260 planes ≈ 3–5 core-hours** — trivial. But random-access reads of
one plane at a time out of an 18.5 GB ND2 are slow and do not parallelise (the reader
holds file state). **Convert once, then read in parallel:**

```
python scripts/_bed_analyze.py convert --to results/bed.zarr --z 0-3
```

Chunk as `(1, 1, 1, 1, 1024, 1024)` — one chunk per `(t, p, z, c)` plane, which is exactly the
access pattern. Expect ~4 GB for z = 0–3, all four channels, uncompressed f32; less with
blosc. **Do this on the login/transfer node once, not in the array.** Add a checksum manifest
so a truncated conversion is detected rather than silently analysed.

**Gate for Phase 0:** `analyze` on 3 planes reproduces the numbers in the evidence log to
within floating-point noise, and `--dry-run` on the full grid partitions 1260 planes with no
gaps or overlaps.

## §2 Phase 1 — fix granule linking *(the blocker; nothing dynamic works without it)*

Mutual-nearest-neighbour on centroids gets 74–93%, and where it is weakest the parent-frame
migration number inverts (see `e049`). **Centroid distance is the wrong metric here.**

**Use mask overlap.** Granules move 8–19 µm per frame while being 50–70 µm across, so
consecutive instance masks overlap heavily. Build the IoU matrix between frame *t* and
*t + 1* instances, solve with `scipy.optimize.linear_sum_assignment`, and accept a match only
above an IoU floor. This is strictly stronger than centroid distance because it uses shape and
extent, and it degrades gracefully when a granule is split differently between frames.

```python
def link_instances(lab_a, lab_b, *, iou_min=0.35):
    """Hungarian assignment on IoU.  Returns a->b map (0 = unmatched) and the IoU achieved."""
```

**Padding matters**: allow unmatched rows and columns at a fixed cost so a granule may appear,
disappear, merge or split without forcing a bad match — the same padded-assignment pattern the
V2.22 plan specifies for dot correspondence.

**Acceptance gates, all three required:**

| Gate | Threshold | Why |
|---|---|---|
| Mutual match rate | **≥ 95%** per consecutive pair | 74–93% is what broke it |
| Parent-frame / lab-frame step ratio | **< 1.0** at every condition | a ratio ≥ 1 means the parent jitters more than the cell moves |
| Apparent cell-transfer rate | **≤ 10%** | 20–45% is implausible for real transfer over 11 h and is the symptom of label flicker |
| Plan invariant | parent's `track_id` constant across the child's track | already specified in V2.22's cross-node tests |

**Then, and only then, requote the parent-frame migration.** Both previous numbers are
retracted (`e049`): −26 to −43% used fragment parents, +50 to +76% used flickering ones.

**Second output of this phase, for free:** with stable identity, **per-granule velocity and
displacement become measurable**, which is the "position tracked over time" half of the
original deliverable. Rotation still needs the interior beads.

## §3 Phase 2 — extend past a single plane

Two separate questions, often conflated.

**2a. Is the finder valid at other z?** It is tuned and validated at z = 1 only. Run it at
z = 0–3 and check *internal consistency*: granule count per unit foreground area, the size
distribution, and the merge-signature rates should track smoothly with depth, not jump.
Where they jump, the plane is outside the usable range. **Do not re-tune σ and h per plane
without labels** — that is fitting to noise. If a plane needs different parameters, that is
evidence it should be excluded, not re-tuned.

**2b. Can instances be linked ACROSS z to get volumes?** This is the volumetric deliverable.
Measured axial IoU is **0.20–0.41 at large granules and 0.06–0.20 at small ones** — enough to
*link* an instance across planes and bound its z-extent, not enough to constrain tilt. So:

- Use the same overlap linker along z instead of t. A granule becomes a chain of 2D instances.
- **Volume = Σ(area × z-step)** over the chain — a slab sum, not a fitted body. Honest, and it
  is the number the fourth deliverable needs.
- **Report the z-extent in planes**, and refuse a volume for any chain of length 1 (a granule
  seen in one plane has an unbounded z-extent at a 40 µm step).
- **Do not fit a 3D shape.** Sampling is 23× anisotropic and 3.9–5.1× undersampled in-plane;
  a fitted ellipsoid would report a precision the data cannot support.

**Gate:** the 2D area fractions and the z-summed volume fractions must agree within ~10%
(Delesse), computed only over planes that pass QC. Disagreement larger than that means the
z-linking is wrong, not that stereology is.

## §4 Phase 3 — the full sweep, and what it is for

**1260 planes** (21 positions × 15 timepoints × 4 usable z). Per plane, emit:

- thresholds used, and the **gate verdict** (pure-F wells must show ~zero inert)
- **QC flags**: level test (does the channel carry the signal the design implies?) and
  continuity test (does any phase fraction step discontinuously between adjacent frames?)
- phase fractions: F, I, cells, void
- per-granule rows: id, centroid, area, solidity, Feret, inscribed diameter, lobe count
- per-cell rows: id, centroid, area, intensity in all three channels, parent id, parent-local
  coordinates
- void attribution: → F, → I, and the >60 µm unattributable remainder

**The 21-condition design is the analysis, not the sample.** With QC applied, regress:

1. **Void fraction against F fraction** (0.5 / 0.75 / 1.0) — six conditions per F size class,
   so this is a dose-response with replication rather than a self-consistency check.
2. **Void fraction against inert size** (S/M/L) at fixed ratio.
3. **Phase-normalised void** (`void-share ÷ own-solid-share`) — the ~45% inert excess is
   currently two conditions; the full sweep makes it 12.
4. **Δvoid over 11 h against condition** — which formulations compact and which dilate.
5. **Cell F-over-I preference against inert size and ratio** — currently 6–15× at three
   conditions.

**Expect to discard ~1 field in 3.** Report the count and reason; a silent exclusion is worse
than a bad field.

## §5 Phase 4 — the statistics that need the full sweep

**Clustering — and the false-positive control is the hard part.** The primary test is a
**join-count permutation** on the granule contact network: relabel F/I species while holding
positions *and* the network fixed. **It must be size-stratified**, because the design varies F
and I size independently — in `SF-LI` the two populations differ by >2.5× by construction, and
a naive `g(r)` would report clustering from excluded volume alone.

**Validation requirement before any clustering claim:** the statistic must report
*non*-significance on a randomly relabelled packing. Run that first.

**Ruled out, do not attempt:** coordination number. In 2D, mean cell degree is pinned near 6
by Euler (`E = 3F − 6`; measured 1338 edges vs 1356 predicted), so it carries no packing
information, and the measured `Z̄` is method-dependent and structurally forced. The defensible
statement is "this acquisition cannot measure in-plane coordination."

**Where curve-shaped outputs live:** `g(r)` and `K(r)` are functions of `r`, and no current
domain holds one. A structure table whose rows are `r`-bins is the answer — this remains
undesigned and needs a decision before building.

## §6 Phase 5 — the nodes

V2.22's increment ladder stands, with these revisions forced by measurement:

| Increment | Revision |
|---|---|
| 3 seeding | **default becomes intensity h-maxima** (σ 4.0, h 0.15), EDT h-maxima demoted to an alternative Mode. Gate: **> 88.9% held-out exact count** against the 585 labels, over-split ≤ 3%. |
| — new | **`analysis.select_objects` gains a size-fraction test** — the phantom-inert fix is "keep components ≥ k × a reference area", a general primitive. |
| — new | **A field-quality gate node**: level + continuity tests per `(m,t,c,z)`. Distinct from object rejection, and general. |
| 8 relax | the intensity term is **unavailable for the saturated F channel**. Make `λ_I` per-channel and default it to 0 where saturation exceeds a threshold, rather than silently trusting clipped values. |
| 10 metrics | per-granule velocity unblocks once §2 passes. Rotation stays gated on the interior beads. |
| 11 void | now designed: three-phase segmentation + nearest-surface attribution + the >60 µm unattributable class, with the `p_k(v)`-weighted version as the principled upgrade. |
| 12 validate | `--suite real` runs the §4 sweep. **Validate on a mixed position, never a pure-F control**, and never on M21 or M04. |

**Charter unchanged and non-negotiable:** every node is a general primitive, no `op_key`

## §7 Order, and what blocks what

```
Phase 0  cluster-runnable CLI + zarr convert      ← nothing runs without this
   │
   ├── Phase 1  overlap linking                   ← BLOCKS all dynamics
   │      │
   │      └── per-granule velocity, parent-frame migration (requote)
   │
   ├── Phase 2a  finder validity at z = 0-3       ← independent of Phase 1
   │      │
   │      └── Phase 2b  z-linking → volumes       ← needs 2a AND the Phase 1 linker
   │
   └── Phase 3  full 1260-plane sweep             ← needs 0; better with 1 and 2
          │
          └── Phase 4  design regressions + clustering
                 │
                 └── Phase 5  the nodes, with every default now measured
```

**Do Phase 0 and Phase 1 before any large run.** A 1260-plane sweep with broken linking
produces 1260 planes of unusable dynamics, and the per-plane cost is the same either way.

## §8 Standing rules, each from a specific failure this project already had

1. **Render it and look at it before it sets a default.** The origin failure was a size prior
   from an unviewed pipeline, wrong by several fold, written into a plan as fact.
2. **A sweep whose optimum sits on a boundary has found the edge of the box, not an optimum.**
   Happened twice — solidity at 0.800 and h at 0.20.
3. **Cross-validate anything fitted to labels, holding out a whole condition.** If every split
   picks the same parameter, say so; that is stronger evidence than the score.
4. **Never apply a blanket correction where the effect is conditional.** Three instances: a
   global α for a cell-localised dye effect; a threshold floor that pushed the cut past the
   sensor ceiling; a phantom-inert fix applied to a channel that never needed it.
5. **Separate a broken method from bad data.** A gate that fails on a bad field teaches
   nothing — judge the method only on fields that carry signal, and flag the rest.
6. **Two masks, two purposes.** Phase accounting excludes cells so the phases partition;
   parent lookup must not, or every cell reads "in void". This bug appeared twice.
7. **Report the retraction, not just the correction.** `log.jsonl` is append-only for this
   reason: in six months the question will be why a threshold is 0.798 and not 0.93.
