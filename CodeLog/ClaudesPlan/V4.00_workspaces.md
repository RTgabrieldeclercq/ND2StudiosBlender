# ND2Studios V4.00 "Workspaces" — typed node-graph pages, named cross-page flow, dockable multi-panel shell, analysis toolkit

## Context

Today the app is one window holding exactly one graph: `MainWindow` owns one `GraphDocument`,
one `GraphScene`/`GraphView`, one `EngineRunner`, one primary `ViewerPanel` (plus an optional
compare pane). Every node type is available everywhere, grouped in the palette by the five
pipeline stages of `codemap/node_roles.json`. Panels are `QDockWidget`s that can be moved but
not floated or closed, and the layout is never persisted. There are no plotting nodes.

The user wants a Blender-style **workspace**: several node-graph **page types** — Image Input,
Image Refinement, Image Processing, Analysis — each with its own node set, each page a separate
graph, and **named outputs** flowing from one page type into the next type's Input nodes.
Many pages per type; a page may be a unique copy or **dependent on a master** (same nodes,
different parameter values) so one workflow can be tuned per position/condition without
losing earlier attempts. A **page switcher** at the top-left of the canvas changes the page;
the page under the mouse decides what the node menu shows and what the viewer displays.
Every section (canvas, viewer, node menu, properties) must **pop out** into its own window or
dock back, with **multiple instances** allowed. Clicking a visual-output node switches the
current viewer to it. The Analysis page needs presentation-quality plots and cross-page
synthesis. The work is split into PR-sized steps that each leave the gates green and the app
usable, under a new version name.

## Architecture (what every step builds toward)

```
Workspace (Qt-free, nodelab_v2/workspace.py)
 ├─ pages: ordered {pg1: Page(name, kind, doc: GraphDocument | LinkedDocument, master, overrides)}
 ├─ kinds: input(0) < refine(1) < process(2) < analyze(3); free (unordered, allows all ops)
 ├─ page.output(data, name)  ──named variable──▶  page.input(source="pgX:name") on a LATER kind
 ├─ compose(pid) → ComposedGraph(graph with ids "pg/n", meta_seeds, id_map, revision digest)
 │      splices every upstream page in (page.input dropped, consumer rewired to upstream Output)
 └─ implements GraphSource for ONE EngineRunner (shared Memo/TileCache → cross-page reuse)

MainWindow(DockShellMixin, QMainWindow)          nodelab_v2/shell.py, canvas.py, layout_store.py
 ├─ docks: canvas:N (CanvasPanel = GraphView+HUD bound to a page), viewer:N, palette:1, inspector:1,
 │         spreadsheet:1, console:1, lablink:1, movie:1 — all Floatable|Closable|Movable, objectNames
 ├─ scene_for(page_id) cache (one GraphScene per page); active canvas → workspace.active → palette kind
 ├─ viewers: list[ViewerPanel]; each bound to (page_id, node_id); active viewer gets clicks/picks
 └─ properties doc/scene/view/viewer/viewer2/_viewed/_viewed2 → active canvas/viewer (probe shims)

Catalog additions: page.input / page.output (GUI-layer ops in ops.py), plot.xy/distribution/heatmap/
timeseries + io.write_figure (nodegraph/catalog/plot, _shared/figure.py), table.concat/join/aggregate.
node_roles.json schema/2: "pages" section, per-role "pages", "op_pages" overrides, new roles
page_boundary, plotting, table_synthesis.
```

- `__source__` keyed on node id: cross-page reuse works only if **every** page is qualified, including the target. No bare-id shortcut.
- `last_touched` forwarding (`None` vs `()`) through the Workspace, or the queue-draining regression returns.
- `repropagate` must run in topological order (iterate unroll reads `envs`).
- Dock-store collisions across pages without `store_tag`; re-anchoring all pages on save.
- Floating a GL viewer on Windows paints one black frame; `_last_planes` replay covers it; the glyph alignment fix is per-upload so it holds on a new context.
- `restoreState` needs docks with matching objectNames created first; reject incompatible layouts cleanly.
- matplotlib: never `pyplot`/`rcParams` on worker threads; first-run font cache takes seconds; `unit="mm"` must be checked against the socket contract.
- `LinkedDocument` in-place mirroring must keep record identity or the canvas rebuilds every card on each master keystroke.
