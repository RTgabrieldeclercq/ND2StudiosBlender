## What changed

V4.00 step 7 of `CodeLog/ClaudesPlan/V4.00_workspaces.md`: **the analysis toolkit I —
matplotlib, Picture datasets, `plot.xy`, `io.write_figure`.**

- **`plot.xy` (Plot XY, category `plot`).** Draws one column of a Label, Point or Track table
  against another (`domain`, `table`, `x`, `y`), one series per `group_by` value; `error`
  sd / sem / ci95 averages the rows that share an x and draws mean ± spread as bars or a band.
  `style` (paper / talk / poster / dark) sets the figure's size in millimetres, its dpi, type,
  line and marker sizes; `detail = custom` exposes them (starting from the paper values);
  `palette`, title, axis labels, `x_range` / `y_range` (`low, high`) and log axes. Footprint:
  the whole table at once (`WHOLE_SERIES`, no kernel axes).
- **The Picture dataset.** A plot's output is ONE RGB image — axes `(1, 1, 1, 3, H, W)`,
  uint8 — with fresh metadata: `bit_depth = 8`, channels R/G/B with `channel_colors`,
  `picture = "rgb"`, the `figure_spec` it was drawn from, and no calibration (so no scale bar,
  no µm readout). Its size is predicted at edit time by `figure_frame` from the same
  `figure_pixels` the render uses (INV-04 holds exactly, custom sizes included).
- **`NodeSpec.fresh_output`** (engine): a node whose output is a NEW Dataset inherits no
  domain, structure layer or column at edit time — the envelope used to keep promising the
  input's tables downstream (layer and column pickers offering what the picture does not
  carry); `passes_domains=False` only ever covered auxiliary inputs.
- **`io.write_figure` (Export Figure).** Writes the figure as PNG, SVG, PDF or TIFF by drawing
  it AGAIN from `figure_spec` — a raster at the export's own `Resolution` (same layout, more
  pixels), vector files with editable text (SVG text stays text, PDF fonts embed as TrueType);
  atomic through `<stem>.part<ext>`; a pass-through tap; refuses a non-figure input (pointing
  to Export TIFF), an empty path, an extension naming another figure format, and an existing
  file under `refuse`.
- **The Viewer shows a Picture as drawn**: its channels in their own `channel_colors` and a
  fixed 0–255 window (no percentile stretch, no auto-contrast) — otherwise a mostly-white chart
  was stretched per channel and could render black.
- **`nodegraph/catalog/_shared/figure.py`**: style presets and palettes (Okabe–Ito by
  default), `resolve_style` / `style_from_ctx`, the shared style sockets and modes, `xy_series`
  (grouping, mean ± sd / sem / Student-t 95 % CI), `draw` / `render_rgb` / `render_file` via
  matplotlib's object API and the Agg canvas only (never `pyplot`; thread-safe — two threads
  render byte-identical pictures), `picture_dataset`, `figure_frame`.
- **Plumbing:** `matplotlib>=3.8` joins the core requirements (and the nodes refuse with the
  install line when it is missing; their tests skip); role `plotting` (Analysis pages) and
  `io.write_figure` in Input / output (Analysis); theme colour for `plot`; MANUAL §15 rows;
  catalog baseline, synopsis and codemap regenerated. The role-count prose in `roles.py` and
  CLAUDE.md no longer states a number (it had gone stale at 19); WF-04 no longer says three
  GUI-layer ops (V4 made it five) and WF-05 states the `fresh_output` rule; CON-01, CON-12,
  INV-03 and WF-04 re-read against the new `define_node` and re-blessed.

plot helpers in every node's memo fingerprint closure. The `existing` mode is overwrite /

## Why

V4's Analysis page needs presentation-quality output from the measured tables. A plot as a
DATASET rather than a side window means it is pulled, cached, viewed, exported and published
like everything else, and that one figure spec can be drawn at any resolution or as a vector
file. Re-rendering from the spec on export, rather than writing the viewer's pixels, is what
makes a 600 dpi PNG and an editable SVG of the same figure possible.

## Review

An adversarial review (three lenses: nodes, envelope/engine, GUI; every finding reproduced by
an independent verifier) confirmed 14 findings; 12 were introduced here, 2 were older. All
are fixed, each with a regression check (`test_plot_review`, probe PL2):

- **Grouping was O(rows x groups)**: 22 s per pull on a tracked table grouped by id. Now one pass
  that buckets rows by value (`group_parts`): 90k rows / 1500 groups in 0.08 s.
- **NaN group values** made one empty series per NaN row in a run-dependent order. Rows with
  no value now form ONE `(missing)` series, last; past 12 series the legend is left off.
- **Log axes were not thread-safe** (matplotlib mathtext parser): concurrent pulls raised
  `ParseException`. Every render now holds one module lock; a 100 Mpx budget refuses a typo'd
  size before allocating.
- **Plot XY's default drew a zig-zag line** through every object; it now scatters.
- **Export Figure's resolution was unbounded** (6000 dpi = gigapixels); clamped to 50–1200,
  and a path naming a folder is refused.
- **Group by could not go back to blank** in Properties or on the card: optional column
  sockets now offer `(none)`.
- **The picture had no domain at all**, so Export TIFF / Movie after a plot were flagged
  "needs voxel"; `fresh_output` nodes now declare their own `adds_domains` (Voxel) and
  `NodeSpec.out_domains` honours it.
- **The source's channel names and colours leaked** onto the picture's R/G/B downstream; the
  envelope now stamps R/G/B and `channel_descriptors` stops inheriting at a fresh node.
- **`fresh_output` was invisible** to the catalog snapshot and the codemap card; both record it.
- **Export Movie and the Movie Editor** drew a picture with grey tints and percentile windows;
  a picture now keeps its channel colours on 0–255.
- **LabLink**: a recipe drafted from a graph ending in a plot targeted the plot (empty
  measurements); drafts now skip `plot.*` / `io.write_figure`, and a picture's quicklook is
  its own RGB.
- *(older)* Track Objects did not declare `track_id` when its labels socket was blank, so
  Group by could not offer it; it now resolves the only candidate layer.
- *(older)* Pulling the viewed node again during an F9 scoped re-pull recursed until
  `RecursionError`; the runner's serve path now has a re-entry guard.
