## What changed

Three new plot nodes on the Analysis page, each drawing a true-colour Picture like Plot XY:

- **Plot Distribution** (`plot.distribution`): one column's spread per group as a histogram
  (groups share bins; count / density / percent), kde, box, violin or ecdf.
- **Plot Heatmap** (`plot.heatmap`): a table summarised on a grid — one cell per (row value,
  column value), reduced by mean / median / sum / min / max / count / std, empty cells blank —
  or a Voxel layer's plane at a chosen frame and position (Z max-projected, pooled to 512 px),
  with a colour bar, a colour map and a fixable colour range.
- **Plot Time Series** (`plot.timeseries`): a column over the experiment's own clock —
  elapsed time from the file's per-frame clock (`frame_time_jd`), else frame x `dt_s`, else the
  frame index with an axis label saying so; wall-clock time; or the frame — each frame's rows as
  mean ± sd / sem / 95 % CI (sem and a band by default), one curve per group.

**Per frame** (`per` mode on Plot XY and Plot Time Series) makes one figure per frame of the
input instead of one: a lazy `FigureProvider` draws frame t when it is read (8 kept), every
frame on the axes the whole data spans, its time in the title; Plot Time Series draws the
course up to the frame with a dashed cursor. The picture carries the input's T and per-frame
clock on both the payload and the envelope, so the Viewer scrubs it, its timestamp works, and
Export Movie animates it. Export Figure gains a `frame` socket that picks which frame of a
per-frame figure to write.

Every step 7 review lesson applies to the new nodes: one-pass grouping with missing values as
one `(missing)` group (a Heatmap's missing row / column values likewise), the render lock and
pixel budget, the legend cap, the Voxel domain and R/G/B channels on the envelope.

Tests: `test_plot_distribution`, `test_plot_heatmap`, `test_plot_timeseries`,
`test_plot_per_frame`, `test_plot_groups_and_frames`, `test_plot_frames_review`. GUI probe: PL3 (a per-frame Plot XY of a
three-frame series scrubs in the Viewer; an Analysis page offers the three new nodes).

## Why

The V4 plan's Analysis toolkit II: a scientist's next questions after a scatter are how a
measurement is distributed, how it varies across positions and frames, and how it changes over
the experiment's real time. The time axis is read from the file's own clock rather than
assumed evenly spaced, because ND2 time-lapses are often not. Per-frame figures are drawn on
demand rather than all at pull time because a 500-frame series would otherwise render 500
figures before the first one shows; drawing them on read keeps a pull as fast as one figure
and lets the Viewer and Export Movie take only the frames they need.

## Review

An adversarial review (three lenses: nodes, envelope/engine, GUI; every finding reproduced by
an independent verifier) confirmed 13 findings, three of them found twice; one more was
refuted as unreachable and hardened anyway. All are fixed, each with a regression check
(`test_plot_frames_review`):

- **A group changed colour between frames** of a per-frame figure when another group was
  absent from a frame. Each frame's series now carry the group's index among ALL the table's
  groups.
- **Heatmap ticks past 40 rows** fell back to matrix indices under an axis named after the
  column (ids 101..160 read as 0..60). Every k-th real value is labelled instead.
- **Histogram bins ignored a fixed X range and a log x axis** (one 333-wide bar in a 0..100
  view; linear bins on log). Bins now span the range, geometrically on log.
- **Per-frame Plot XY clipped its error bars**: the shared y axis came from the raw rows. It
  now spans every frame's mean ± spread, like Plot Time Series.
- **The memo counted a per-frame figure as 0 bytes**, so superseded ones (each holding up to 8
  rendered frames) were never evicted. `FigureProvider.nbytes` reports its fullest cache.
- **Playback drew each frame three times** (R, G and B planes read on three threads, no
  in-flight marker). `FigureProvider.frame` is now single-flight per frame.
- **A live reload of figure.py handed back the old provider** (identity = spec only), mixing
  old and new drawing code. The drawing module's own hash is part of the identity.
- **The 100 Mpx budget was skipped for per-frame figures** until a plane was read; it is
  checked when the series is built.
- **The Viewer prefetched 16 neighbouring figures** on each pull, treating renders as
  decompresses. A provider that `computes_on_read` gets the short span and is not "bytes" for
  playback.
- **Export Movie stamped an R/G/B legend on a chart** (step 7 behaviour, newly visible). A
  picture's movie has no channel legend.
- **Plot Heatmap offered Palette, Grid and Legend that changed nothing.** Palette is gone (the
  colour map colours it); Legend shows the colour bar; Grid outlines a table heatmap's cells.
- *(refuted, hardened)* Plot Time Series raised a bare error on a `t` column with no finite
  value; it now counts only finite frames.

**The GUI probe crashed after passing** (exit 139 after `ALL PHASE-5 GUI PROBES PASSED`, two
runs in a row). `-X faulthandler` showed the main thread in the final `os._exit` while a
LabLink panel thread was mid-way through an HTTP connect: the panel, left on screen by the
dock-shell checks, polls its hub. Not step 8 code, only timing. The probe now stops the
panel's polling and waits for its last request before exiting, as the app's close path does.
