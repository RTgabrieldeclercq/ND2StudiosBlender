# The codemap — find anything in this repo without reading it

**One rule: grep the index, then read the one record. Open a source file only after a record
names it.**

Full record shapes: [codemap/_schema.md](../../../codemap/_schema.md). Everything under
`codemap/gen/` is generated by `scripts/_codemap.py write` and gated by
`nodegraph.selftest.test_codemap`, so it is as current as the last gate run.

## The lookup table

| You want | Do this |
|---|---|
| a node — sockets, footprint, what it does | `grep '"op":"<op_key>"' codemap/gen/nodes.jsonl` |
| don't know the op_key, only a name | `grep -i '"label":"[^"]*<word>' codemap/gen/nodes.jsonl` |
| a param's unit, default, hover prose | `grep '"key":"<op>:in:<param>"' codemap/gen/sockets.jsonl` |
| every socket of one node | `grep '"op":"<op_key>"' codemap/gen/sockets.jsonl` |
| where a symbol lives + its signature | `grep '"id":".*<Name>"' codemap/gen/symbols.jsonl` |
| what a module does, what it exports | `grep '"path":"<path.py>"' codemap/gen/modules.jsonl` |
| who imports X | `grep '"dst":"<dotted.module>"' codemap/gen/imports.jsonl` |
| what X depends on | `grep '"src":"<dotted.module>"' codemap/gen/imports.jsonl` |
| a term (`TILEABLE`, `voxel`, a meta transform) | `grep '"t":"<TERM>"' codemap/gen/vocab.jsonl` |
| how a flow works end to end | read one `WF-` entry in `codemap/workflows.md` |
| how many nodes / gate status | `codemap/STATE.md` |

The node card is usually the whole answer: it carries the compute's full docstring (`cdoc`),
the footprint per 2D/3D mode (`gran`), the owning file (`mod`), the param keys the compute
actually reads (`params_read`), and a link to the kernel's integration contract
(`kernel_doc`) when the node wraps one.

## What this repo is, in six lines

A Blender-geometry-nodes-style node editor for microscopy image analysis. `nodegraph/` is the
engine and is **Qt-free**; `nodelab_v2/` is the PySide6 GUI and imports it; `scripts/` is a
leaf. The one sanctioned reversal is `nodegraph/selftest.py`, which imports the GUI to test
the Qt-free seam. **Nodes are not in `nodegraph/nodes.py`** — that is a facade; each node is
one file at `nodegraph/catalog/<category>/<name>.py`.

## Traps

- `CodeLog/Architecture/ARCHITECTURE.md` describes the **deleted v1 app**. `CodeLog/ClaudesPlan/**`
  are dated design records — several superseded, some naming gate scripts that no longer exist
  (`_pipeline_kit_parity.py`, `_pipeline_graph_selftest.py`, `_lablink_conformance.py`).
- `CodeLog/ClaudesPlan/V3.00_catalog_expansion_roadmap.md` is **717 KB (~180k tokens)**. Never
  open it whole.
- `nodegraph/selftest.py` is ~17k lines. Grep for the `test_*` name; never read it whole.
- **Any node count you find in prose is wrong.** `codemap/STATE.md` is the only current one.

## When the map is not the answer

It is checked for existence and shape, never for truth. It says nothing reliable about
performance, GUI runtime behaviour, or *why* a design is the way it is — for that, the
rationale is `CodeLog/Architecture/ENGINEERING_NOTES.md` (2,100 lines; open a section, not the
file). **If code and map disagree, the code wins**; say so in your report so the map gets
fixed.

After two failed lookups, stop grepping and read the code — and name the lookup that failed,
so the gap can be filled.

## Building or changing a node

Do not use this skill for that. Invoke **`build-node-v2`** (procedure) and **`wire-node-v2`**
(concepts); they own that workflow, including the gates a node change must pass.
